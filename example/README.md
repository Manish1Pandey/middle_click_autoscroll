# middle_click_autoscroll example

Run on a desktop or in a browser with a mouse:

```sh
flutter run -d macos   # or: -d chrome, -d windows, -d linux
```

Tabs: vertical list, horizontal list, 2D grid (`TwoDimensionalScrollView`),
nested lists (horizontal-in-vertical and vertical-in-vertical) and controller
mode. The left panel changes mode, dead zone, max speed, speed curve,
indicator and the web browser-default blocking live.
